# Specification

## Summary
**Goal:** Replace the current yellow theme with a clean white theme across the entire application.

**Planned changes:**
- Update CSS color tokens so all backgrounds use white or near-white tones (no yellow remaining)
- Set the sticky header background to white
- Update property cards to white or light gray backgrounds
- Update the hero section to white or very light background
- Change buttons and interactive elements from yellow to neutral/gray accent colors
- Ensure text remains dark and readable on white backgrounds
- Update footer background to match the white theme
- Apply white theme consistently to agent dashboard and form pages
- Update both light and dark mode CSS tokens

**User-visible outcome:** The entire app renders with a clean white theme — no yellow backgrounds remain on any page, card, header, button, or UI element.
